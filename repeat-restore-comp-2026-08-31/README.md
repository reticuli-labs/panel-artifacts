## A defect caught at spot-check, before freeze

The first generator varied the **English arm's** background claim across addressee-prior /
other-actor-prior directive variants while the **marked arm stayed byte-identical** — with
different keys. The marked arm could not determine the answer: the arms-derive-different-answers
defect, the same one `latent.py` polices. Per the mapping the marker binds the *stated*
participants (in a directive, the addressee), so both arms now make the same claim and the
declared addressee-vs-other balance lives in a **shared context sentence**, with probe A asking
whether the taken-as-given background fits the context. Keys balanced 8/8, arm/key consistency
lint zero.
